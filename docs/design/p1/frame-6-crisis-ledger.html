Where the product is going, not P1 scope: a pre-rendered page per crisis, read as an article, with the globe shrunk to a locator. The crisis, its place and every figure are invented. Casualty and severity numbers are static, in plain type, with source and date; the sentence block carries the label the plan requires. docs/design/p5.md specifies this screen before it is built. Colours, sizes and type are the plan’s §4 tokens. The named faces (Inter, JetBrains Mono, Newsreader, Noto Serif) are not embedded: this file falls back to system fonts, so letterforms differ from the target. Land and borders: Natural Earth (public domain), projected ahead of time. No network requests, no scripts beyond the fit-to-width helper.
