The ring stays in the centre of the uncovered globe at each detent. P1 has no V·I·E control, scrubber or Share row on phones yet; chips scroll sideways. Phone type sizes follow the plan: titles 16/23. Colours, sizes and type are the plan’s §4 tokens. The named faces (Inter, JetBrains Mono, Newsreader, Noto Serif) are not embedded: this file falls back to system fonts, so letterforms differ from the target. Land and borders: Natural Earth (public domain), projected ahead of time. No network requests, no scripts beyond the fit-to-width helper.
