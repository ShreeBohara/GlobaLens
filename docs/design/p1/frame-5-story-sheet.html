Where the product is going, not P1 scope: the Lens lists stories instead of single headlines, and a story opens in the 420 px sheet with the ring re-centred in the visible globe. Glosses and their source marks arrive in P2, stories and this sheet in P4. The magnitude line is the plan’s own example. docs/design/p4.md specifies this screen before it is built. Colours, sizes and type are the plan’s §4 tokens. The named faces (Inter, JetBrains Mono, Newsreader, Noto Serif) are not embedded: this file falls back to system fonts, so letterforms differ from the target. Land and borders: Natural Earth (public domain), projected ahead of time. No network requests, no scripts beyond the fit-to-width helper.
