What P1 ships: the Lens ring at a constant screen size over real GDELT points, the headline list with exact copies collapsed, country-level coverage as groups, language chips with their fixed keys, and the two-clock badge. No glosses, window chips, timeline or V·I·E control yet. Colours, sizes and type are the plan’s §4 tokens. The named faces (Inter, JetBrains Mono, Newsreader, Noto Serif) are not embedded: this file falls back to system fonts, so letterforms differ from the target. Land and borders: Natural Earth (public domain), projected ahead of time. No network requests, no scripts beyond the fit-to-width helper.
